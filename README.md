# 🧩 Escape Room Game in Python

An interactive Escape Room-style game built in Python that challenges players to solve puzzles, uncover clues, and escape by navigating through a series of riddles and logic scenarios.

---

## 📖 Overview

This project simulates a text-based Escape Room adventure where players must explore rooms, answer riddles, make decisions, and solve puzzles to progress and ultimately escape. It demonstrates fundamental Python programming concepts such as control flow, data structures, user input handling, and game logic.

---

## 🎮 Features

- Interactive command-line gameplay
- Multiple puzzles and challenges
- Logical decision-making
- Progress tracking as players explore the game
- Engaging storytelling

---

## 🧠 Concepts Covered

- Python control structures (`if`, `while`, `for`)
- Handling user input
- Functions and modular design
- Game loop logic
- State management
